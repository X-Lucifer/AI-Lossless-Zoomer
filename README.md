# AI超分辨工具

## 当前项目由于历史原因, 不再维护, 已采用最新Avalonia和原生C++重写图片处理引擎, 可体验高性能和更美观的界面操作
## 已迁移至最新项目: https://github.com/X-Lucifer/X.SuperResolution

### 说明:
> 本程序使用了来自腾讯ARC Lab提供的`Real-ESRGAN`模型，目前模型主要来自于人像，能对人像进行一个较快的处理，特别是动漫图片，进行一个很好的放大。
